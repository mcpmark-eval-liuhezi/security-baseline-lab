# Security Policy

## Supported Versions

This is a throwaway repository used for a demo of the team's security review procedure.

| Version | Supported |
| ------- | ---------- |
| main    | demo only  |

## Reporting a Vulnerability

This is a demo repository; no real vulnerabilities will be accepted.
Please report any real security issues to the maintainers of the actual project instead.

## Scope

- This repository is intentionally minimal and used only for the audit walkthrough.
- No secrets, credentials, or sensitive data should ever be committed here.
